# Zodiac Compass

An AI-powered product concept that helps users explore personality insights through interactive conversations and visual storytelling.

## Overview

Zodiac Compass is a product concept designed to create a playful and engaging way for users to discover zodiac-based insights through conversational AI.

- AI-assisted Development

- High-fidelity UI

- Front-end implementation using Next.js
